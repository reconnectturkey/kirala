# Lead ve İş Takip MVP (Startkey Loft / KD Ankara)

Bu proje; teknik olmayan kullanıcılar için **hızlı kurulumlu**, sade bir web tabanlı MVP'dir.

## Teknoloji
- Node.js + Express + SQLite + EJS

## Mac kurulum komutları
```bash
mkdir -p ~/Projects
cd ~/Projects
git clone <REPO_URL> kirala-lead-mvp
cd kirala-lead-mvp
npm install
npm start
```

Geliştirme için:
```bash
npm run dev
```

## v0.2 özellikleri
- Lead ekleme
- Lead düzenleme
- Lead listesi
- Sorumlu kişiye göre filtreleme
- Duruma göre filtreleme
- Arama kutusu (ad, telefon, bölge)
- Bugünkü takipler
- Geciken takipler
- Durum değiştirme
- Not ekleme
- Arşivleme / pasife alma ve tekrar aktife alma
